# 🛍️ پلتفرم جامع ربات تلگرام و پنل مدیریت فروشگاهی (Botsaller)

یک پلتفرم کامل، مدرن و غیرهمزمان (Async) مبتنی بر **Python 3.12+**، **Aiogram 3.x**، **FastAPI** و **SQLAlchemy 2.0 Async** به زبان **فارسی (Persian-First)** به همراه پنل مدیریت و پشتیبانی کاملاً راست‌چین (**RTL**) با فونت **وزیرمتن (Vazirmatn)**.

---

## 🚀 ویژگی‌های کلیدی سیستم

### ۱. ربات تلگرام چندسطحی و هوشمند (Aiogram 3.x + FSM)
- **پشتیبانی کامل از ۵ زبان بین‌المللی (i18n)**:
  - زبان پیش‌فرض **انگلیسی (English - Default)** به همراه **فارسی**، **روسی (Русский)**، **چینی (中文)** و **هندی (हिन्दी)**.
  - پرسش خودکار زبان هنگام اولین استارت کاربر (Onboarding) و امکان تغییر زبان در هر لحظه از طریق دستور `/language` یا دکمه منو.
- **منوی اصلی پویا و کاربرپسند**:
  - `🛍 خدمات و ثبت سفارش`: مرور درختی دسته‌بندی‌ها و زیردسته‌ها در سطوح نامحدود.
  - `💳 کیف پول و افزایش موجودی`: شارژ آنلاین تتر (USDT) بر بستر TRC20 و BEP20، تولید QR کد اختصاصی و استعلام آنی هش تراکنش (TXID).
  - `📦 میز کار و سفارش‌های من`: مشاهده سوابق، رهگیری لحظه‌ای و **دانلود فایل نهایی تحویل داده شده** توسط پشتیبانی.
  - `🔑 توکن من`: نمایش توکن امنیتی اختصاصی هر کاربر جهت احراز هویت در سامانه.
  - `🆘 پشتیبانی`: ارتباط سریع با تیم پشتیبانی.
- **فرمساز پویا و هوشمند (Dynamic Step-by-Step Wizard)**:
  - پرسش مرحله‌به‌مرحله سوالات اختصاصی هر سرویس (متن، عدد، تاریخ، لیست انتخابی، عکس و فایل پیوست).
  - پشتیبانی از رد کردن مراحل اختیاری (`⏭ رد کردن این مرحله`).
  - اعتبارسنجی عبارات منظم (Regex) و دانلود امن تصاویر/فایل‌ها در سرور.
- **کسر آنی از کیف پول**:
  - بررسی خودکار موجودی، کسر اتمیک وجه (`SELECT ... FOR UPDATE`)، ایجاد تراکنش و ارسال فوری مشخصات سفارش به گروه/کانال اپراتورها.

### ۲. سوپراپلیکیشن و مینی‌اپ تلگرام (Telegram Mini App - TMA)
- **کاتالوگ ویترینی تعاملی و جستجوی آنی**: ناوبری بسیار روان در دسته‌بندی‌ها، فیلترهای چیپسی و کارت‌های خدمات با محاسبه نرخ لحظه‌ای تتر (USDT).
- **فرم‌ساز زنده با آپلود پیشرفته**: فرم‌ساز پویا با فیلدهای متن، عدد، تاریخ، سلکت‌باکس و آپلود چندرسانه‌ای (عکس/سند) با پیش‌نمایش و Drag & Drop.
- **کیف پول کریپتو و اسکنر QR**: نمایش موجودی زنده، سوابق تراکنش‌ها، کپی یک‌کلیکه آدرس‌های TRC20/BEP20 و ثبت هش تراکنش (TXID).
- **میزکار سفارش‌ها و دانلود مستقیم**: تایم‌لاین بصری وضعیت سفارش، رهگیری زنده و دانلود مستقیم فایل‌های نهایی تحویل داده‌شده توسط پشتیبانی.
- **احراز هویت رمزنگاری‌شده (HMAC-SHA256)**: تایید اعتبار کاربر از طریق پروتکل رسمی `initData` تلگرام با بازخورد لرزشی (Haptic Feedback).

### ۳. اعتبارسنجی خودکار بلاکچین (Crypto Verifier Worker)
- ورکر پس‌زمینه که هر ۳۰ ثانیه تراکنش‌های معلق را از طریق APIهای TronGrid و BscScan راستی‌آزمایی می‌کند.
- محافظت کامل در برابر خرج مجدد و تکرار هش (Anti-Replay Protection).
- واریز خودکار وجه به کیف پول مشتری و ارسال پیام تبریک تلگرامی به محض تایید در شبکه.

### ۳. پنل وب راست‌چین با تفکیک نقش (RBAC)
- **پنل مدیریت کل (`super_admin`)**:
  - **داشبورد آمار**: مجموع درآمد دلاری، سفارش‌های در صف، واریزی‌های معلق و کاربران فعال.
  - **مدیریت درختی دسته‌بندی‌ها**: ایجاد، ویرایش، حذف و چینش دسته‌ها در سطوح نامحدود.
  - **فرمساز اختصاصی (Dynamic Form Builder)**: اضافه و حذف فیلدهای اختصاصی با انواع مختلف برای هر سرویس.
  - **مدیریت و تحویل سفارش**: مشاهده مشخصات مشتری و فایل‌های ارسالی او، تغییر وضعیت و **آپلود فایل خروجی نهایی (که فوراً توسط ربات به تلگرام مشتری ارسال می‌شود)**.
  - **امور مالی و کیف‌پول سرد**: تنظیم آدرس کیف پول‌های سرد، کلیدهای API، مشاهده تراکنش‌ها و افزایش/کاهش دستی اعتبار کاربران با ثبت سند حسابداری.
  - **مدیریت همکاران**: تعریف و فعال/غیرفعال‌سازی حساب‌های کاربری پشتیبانی.
- **پنل پشتیبانی (`support`)**:
  - دسترسی امن و تفکیک‌شده به سفارش‌های نیازمند بررسی دستی (`needs_review`) و صف سفارش‌ها.
  - بازبینی فرم‌های کاربران، مشاهده تراکنش‌های معلق و ارسال فایل خروجی به تلگرام مشتری.

## 🐧 نصب خودکار و آسان در سرور لینوکس (Linux Auto-Installer)

یک اسکریپت نصب اختصاصی، کاملاً تعاملی و به زبان انگلیسی برای جلوگیری از به‌هم‌ریختگی حروف فارسی در ترمینال‌های لینوکس آماده شده است:

```bash
# اعطای دسترسی اجرایی و اجرای اسکریپت
chmod +x install.sh
sudo bash install.sh
```

اسکریپت به صورت گام‌به‌گام و تعاملی موارد زیر را از شما دریافت و پیکربندی می‌کند:
1. توکن ربات تلگرام (`Bot Token`)
2. پورت دلخواه پنل وب (`Web Panel Port` - با بررسی اشغال نبودن پورت)
3. نام کاربری و رمز عبور مدیر کل (`Super Admin Credentials`)
4. انتخاب نوع دیتابیس (SQLite یا MySQL)
5. آدرس‌های کیف پول سرد (TRC20 و BEP20) و کلیدهای API بلاکچین
6. ایجاد خودکار محیط مجازی پایتون (`venv`) و نصب بسته‌ها
7. پیکربندی فایروال سرور (`UFW`)
8. ایجاد و فعال‌سازی سرویس دائمی سیستم (`systemd service`) جهت اجرای خودکار در پس‌زمینه و بالا آمدن پس از ریستارت سرور

## 🔒 راه‌اندازی خودکار دامنه و SSL رایگان برای مینی‌اپ (Domain & Let's Encrypt SSL)

تلگرام برای اجرای مینی‌اپ‌ها (**TMA**) الزاماً نیازمند آدرس **HTTPS با گواهی SSL معتبر** است. یک اسکریپت تمام‌خودکار برای اتصال دامنه، پیکربندی Nginx و دریافت گواهینامه امنیتی رایگان آماده شده است:

```bash
# اعطای دسترسی اجرایی و اجرای اسکریپت تنظیم دامنه و SSL
chmod +x setup_ssl_domain.sh
sudo bash setup_ssl_domain.sh
```

اقدامات خودکار این اسکریپت:
1. بررسی خودکار رکورد DNS و اطمینان از اتصال دامنه به آی‌پی سرور شما
2. نصب وب‌سرور **Nginx** و ابزار **Certbot**
3. ایجاد کانفیگ امن Reverse Proxy برای پورت اپلیکیشن (با پشتیبانی از آپلود فایل و وب‌سوکت)
4. دریافت گواهی SSL رسمی از Let's Encrypt با تمدید خودکار ۹۰ روزه
5. فعال‌سازی ریدایرکت خودکار HTTP به HTTPS
6. به‌روزرسانی مقدار `MINIAPP_URL` در فایل `.env` و ری‌استارت سرویس Botsaller

## 🛠️ راهنمای راه‌اندازی و اجرای دستی (Manual Setup)
- پایتون نسخه 3.11 یا بالاتر
- توکن ربات تلگرام (از طریق `@BotFather`)

### ۲. نصب وابستگی‌ها
```bash
cd botsaller
pip install -r requirements.txt
```

### ۳. پیکربندی متغیرهای محیطی
فایل `.env` را باز کرده و توکن ربات تلگرام خود را جایگزین نمایید:
```env
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrSTUvwxYZ
DATABASE_URL=sqlite+aiosqlite:///./botsaller.db
# برای استفاده از مای‌اس‌کیوال:
# DATABASE_URL=mysql+aiomysql://root:password@localhost:3306/botsaller

SECRET_KEY=super-secret-key-change-this-in-production-simorix-2026
ADMIN_DEFAULT_USERNAME=admin
ADMIN_DEFAULT_PASSWORD=admin123
WEB_HOST=0.0.0.0
WEB_PORT=8000

COLD_WALLET_TRC20=TXYZ1234567890ExampleTRC20Address
COLD_WALLET_BEP20=0x1234567890abcdef1234567890abcdef12345678
```

### ۴. اجرای سامانه
پروژه را با دستور زیر اجرا کنید:
```bash
python main.py
```
یا با استفاده از `uvicorn`:
```bash
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

## 🔑 ورود به پنل مدیریت
پس از اجرای سرور:
1. مرورگر خود را باز کرده و به آدرس `http://localhost:8000/login` بروید.
2. با اطلاعات پیش‌فرض وارد شوید:
   - **نام کاربری**: `admin`
   - **رمز عبور**: `admin123`
3. می‌توانید از بخش **مدیریت همکاران**، حساب‌های پشتیبان جدید با نقش `support` ایجاد کنید.
